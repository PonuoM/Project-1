## 1. Current version, classes and ascendancies (with patch added and signature mechanic)

### Takeaway
As of Oct 2026 the live game is **Early Access 0.5.x "Return of the Ancients"** (0.5.0 launched 29 May 2026; 0.5.5 one-month event update went live 4 Sep 2026). ### Inferences
- Count by patch: 12 (0.1) → 17 (0.2) → 17 + Abyssal Lich variant (0.3) → 20 (0.4) → 22 (0.5). The design pattern is to ship a class with 2 ascendancies and add the 3rd later.
- The common ascendancy template is about 14–15 nodes in a mini-tree with 8 points, so a player takes roughly half. Notables either (a) grant a unique skill or companion (djinn, spirits, Manifest Weapon, Temporal Rift), (b) break a core rule (Ring slot, Chest storage, Life cannot change while you have ES, ignore requirements), or (c) give large "more" multipliers (50% more damage, 30% less damage taken).
- Some ascendancies modify the passive tree itself: Pathfinder Path Seeker (alternate start + 4 points), Oracle Entwined Realities (unconnected allocation), and Oracle's +1 passive point node. These are a good template for idle "meta-tree" upgrades.

### Gaps
- Exact patch notes for Pathfinder/Acolyte availability at the 6 Dec 2024 launch were not checked. Sources suggest all 12 original ascendancies existed in 0.1.
- Full notable lists with exact numbers for every ascendancy were not gathered; only examples above. Some poe2db texts are partial lines of multi-line nodes.
- Third-party one-line summaries (Timesaver) conflict in places with datamined text. Example: Timesaver describes Ritualist as "Mist, blood offerings", while Maxroll says it steals rare modifiers. Datamined text was preferred.
- I could not access the official 1.0 class list. Only the Duelist is confirmed; Templar, Marauder and Shadow at 1.0 are unconfirmed.

## 2. Passive tree structure (nodes, points, node types, attributes, starts, regions, jewel sockets)

### Takeaway
There is one shared tree with **6 start areas** (2 classes per attribute combination). The tree has thousands of nodes: Fextralife estimates "1800+ small, 500+ non-small, 16+ keystones", and poe2db lists 33 keystones. A character gets about **123 points (99 from levels + 24 campaign)**, plus about 2 endgame points, which is roughly 125. Node types are travel/attribute (+5 to a chosen Str/Dex/Int), small, notable, keystone, and jewel socket. There are **no Life nodes** and no PoE1-style Masteries.

### Inferences
- About 125 points against about 2,300 nodes means a character allocates roughly 5% of the tree. Scarcity is the depth driver: every build is a "path" through a few theme clusters plus 1–3 keystones.
- Typical magnitudes for an idle-game port:
  - Small nodes: about 8–15% increased of one stat, or +5 attribute.
  - Notables: about 20–40% increased, or a conditional or rule-changing effect.
  - Keystones: a big upside with a hard drawback.
- Sharing start areas between 2 classes of the same attribute pair is a cheap way to make "class" mean "start position + ascendancy" while reusing one tree. It is ideal for an idle game with limited content budget.

### Gaps
- No authoritative exact current total node count, small-node count or jewel-socket count for 0.5 was found. poe2wiki and poe2db tree pages could not be read.
- The full 12-class start-pair mapping is not confirmed by a single source. The likely pairs are Warrior/Marauder (Str), Ranger/Huntress (Dex), Witch/Sorceress (Int), Mercenary/Duelist (Str/Dex), Monk/Shadow (Dex/Int) and Templar/Druid (Str/Int). Only Witch/Sorceress and Templar/Druid are cited.

## 3. Weapon set passive points (dual specialization)

### Takeaway
Weapon Set points are not extra points. They let up to **24** of your regular points be allocated per weapon set, so nodes assigned to Set I are active only with weapon set 1 and Set II nodes only with set 2. Each set can hold a different 24-point branch. In practice this gives two partially different trees (e.g. AoE clear vs single-target, or offense vs defense), and the game auto-swaps sets when you use a skill bound to a set.

### Cited Findings
- Requirements:
  1. A Weapon Set Point Maximum above 0 (example screenshot: 24, acquired during the campaign).
  2. Unallocated skill points, assigned to a Weapon Set "instead of globally".
  3. Selecting Set I or II in the UI.
  - Global nodes stay active regardless of weapon. Maxroll's example puts AoE nodes on Set 1 and single-target damage on Set 2.
  - Source: [Maxroll](https://maxroll.gg/poe2/resources/poe-2-passive-tree-and-dual-specialization)
- Weapon set points "require an equivalent number of unallocated regular passive skill points" and "do not inherently grant extra passive skill points". [poe2wiki Weapon set (wiki snippet)](https://poe2wiki.net/wiki/Weapon_set) also says:
  - Up to 24 Weapon Set points can be gained in the campaign.
  - The wiki lists 24 for Set 1 and 24 for Set 2 separately, "with a third set for Shapeshift skills" (Druid).
  - "Keystone passive skills and jewel sockets cannot be assigned to separate weapon sets."
  - Refunding requires removing one point from each weapon set to reclaim a single normal passive point.

- The wiki snippet attributes Weapon Master to Witchhunter, converting up to 100 regular points into weapon-set points. ### Inferences
- Net effect: with 24 weapon-set points a character effectively owns up to 24 "situational" nodes per set. That is about 24 bonus nodes, active only in context.
- This is a strong, simple idea for an idle game: two loadouts (e.g. "Clear" vs "Boss") that share most of a tree, with a capped number of swap-only nodes, auto-switched by encounter type.
- Excluding keystones and jewel sockets keeps build identity global and stops abuse.

- The Druid's shapeshift "third set" mechanics (point count) were not detailed.

## 5. Jewels (types, radius, how they modify the tree)

### Takeaway
Jewels sit in tree sockets (about 12 per the wiki) in three families:
- **Regular jewels** (Ruby = Str/martial/armour, Emerald = Dex/evasion/range, Sapphire = Int/ES/caster, plus a Diamond base for uniques): flat stats.
- **Time-Lost jewels**: radius jewels that add bonuses to the small or notable nodes inside their radius.
- **Timeless jewels**: "Conquer" all passives in a large radius for a faction and can grant special keystones; only one "Historic" jewel allowed.

Unique jewels bend tree rules: allocate unconnected, allocate from another class start, copy notables, extra sockets.

### Cited Findings
- Base types: Ruby, Emerald, Sapphire, Diamond; Time-Lost Ruby/Emerald/Sapphire/Diamond ("local jewel effect base radius [1000]"); Timeless Jewel. — [poe2db Jewels](https://poe2db.tw/us/Jewels)
- **Time-Lost jewels**: per [Timesaver 0.5 guide](https://timesaver.gg/blog/poe2-time-lost-jewels-guide):
  - Emerald = Dex theme, Sapphire = Int, Ruby = Str, Diamond = wildcard (unique Against the Darkness).
  - Example mods: "Small Passive Skills in Radius also grant (1–2)% increased Attack Damage"; "Notable Passive Skills in Radius also grant (3–7)% increased Magnitude of Ailments you inflict."
  - Up to 3 prefixes and 3 suffixes.
  - Drop level 20.
  - A Vaal Orb corruption can upgrade the radius to Large.
- Ruby, Sapphire and Emerald Time-Lost jewels roll Medium or Large radius. Against the Darkness is fixed Large and drops from Zarokh, the Temporal. — [u4gm](https://www.u4gm.com/path-of-exile-2/blog-how-to-get-time-lost-jewels-in-path-of-exile-2-a-detailed-guide)
- Fextralife lists radius values such as Large 1500. Radius numbers conflict across sources. — [Fextralife](https://pathofexile2.wiki.fextralife.com/Time-Lost_Diamond)
- Mod tendencies: Emerald = range/evasion, Sapphire = ES/caster, Ruby = martial/armour. — [Sportskeeda](https://www.sportskeeda.com/mmo/path-exile-2-poe2-time-lost-jewel-get-use-how)
- **Timeless jewels**: all from [poe2db Timeless](https://poe2db.tw/us/Timeless_Jewel)
  - Heroic Tragedy (Kalguuran): "Passives in radius are Conquered by the Kalguur"; "Remembrancing (100–8000) songworthy deeds by the line of Vorana".
  - Undying Hate (Abyssals). Note: "Desecration makes this item unstable".
  - Faction mods also exist for Vaal (Xibaqua), Karui (Kaom), Maraketh (Balbala), Templars (Maxarius) and Eternal Empire (Cadiro).
- Heroic Tragedy has a Very Large/Large (1500) radius. Only one Historic jewel can be socketed. — [poe2db Heroic Tragedy (search snippet)](https://poe2db.tw/us/Heroic_Tragedy)
- **Unique jewels** with tree-rule effects: all from [poe2db Jewels](https://poe2db.tw/us/Jewels)
  - "From Nothing: Passives in Radius of [Passive Skill] can be Allocated without being connected to your tree"
  - "Split Personality: Can Allocate Passive Skills from the Sorceress's starting point"
  - "Megalomaniac: Allocates [notable]" (×3)
  - "Controlled Metamorphosis: Only affects Passives in Medium-Large Ring; (-20—-5)% to all Elemental Resistances"
  - "Prism of Belief: +(1—3) to Level of all [Specific] Skills"
  - "The Adorned: (0—150)% increased Effect of Jewel Socket Passive Skills containing Corrupted Magic Jewels"
  - "Flesh Crucible: Random 1 Keystone Passive Skill; (20-10)% less [random stat]"
  - "Voices: Allocates 2/3/4 Sinister Jewel sockets"
  - "Grand Spectrum Ruby/Emerald/Sapphire: 2% increased Maximum Life / 2% increased Spirit / +6% all Elemental Resistances per socketed Grand Spectrum"
  - "Heart of the Well" has desecrated mods
- Sinister sockets (from Voices) hold regular jewels only. Time-Lost radius effects do nothing there. — [Timesaver](https://timesaver.gg/blog/poe2-time-lost-jewels-guide)
- Lich (0.2) can "empower a Jewel to increase its power, but also mana cost". — [search summary of 0.2 coverage](https://mobalytics.gg/poe-2/guides/dawn-of-the-hunt-reveal)
- In 0.5, the Unsavored Feast notable on a Timeless jewel was changed to "Leech Life 35% faster at 100 Tribute". — [official 0.5.0 notes](https://www.pathofexile.com/forum/view-thread/3932540)

### Inferences
- Jewel design gives three layers of tree customization:
  1. Flat stat sockets (a reason to path to socket nodes).
  2. Radius modifiers (make a region of the tree stronger, which rewards clustering).
  3. Rule-breakers (unconnected allocation, foreign start, keystone grant).
- For an idle game, a radius "aura" jewel that buffs every node within N hops is an easy, high-depth mechanic.

### Gaps
- Exact current radius values per size (Small/Medium/Large/Very Large) conflict between sources and were not verified for 0.5.
- The full list of Timeless jewel names besides Heroic Tragedy and Undying Hate (Vaal, Karui, Maraketh, Templar, Eternal Empire uniques) was not retrieved.
- The jewel socket count (12) may be outdated after the 0.3 tree expansion.

## 6. Ascendancy unlock (trials, points per trial, total)

### Takeaway
There are **8 ascendancy points total, granted in 4 pairs of 2**. They come from either the **Trial of the Sekhemas** (Act 2, roguelite runs with Barya keys) or the **Trial of Chaos** (Act 3, Ultimatum-style waves). The two trials are interchangeable; either alone can grant all 8. The first 4 points come in the campaign and points 5–8 in endgame at level 60–75+. The first completion of any trial unlocks the ascendancy class.

### Cited Findings
- Per [Maxroll](https://maxroll.gg/poe2/getting-started/trials-of-ascendancy) (updated for 0.5.3, 21 Jun 2026):

  | Ascension | Points | Trial of the Sekhemas | Trial of Chaos |
  |---|---|---|---|
  | 1st (unlocks class) | 1–2 | Balbala's Barya, Act 2 quest | Any first completion |
  | 2nd | 3–4 | — | Chimeral Inscribed Ultimatum, Act 3 quest |
  | 3rd | 5–6 | Level 60+ Djinn Barya, "Number of Trials: 3" | Level 65+ Inscribed Ultimatum, "Number of Trials: 10" |
  | 4th | 7–8 | Level 75+ Djinn Barya, 4 trials + pinnacle boss | Level 65+ Inscribed Ultimatum, 10 trials + Cowardly, Deadly and Victorious Fate fragments |

  - The Chaos requirement was lowered from 75+ to 65+ in 0.2.0f (16 Apr 2025).

It lists Balbala's Barya (Lv22), Djinn Barya 2/3/4 trials (Lv38/60/80), and Trial of Chaos 4/10 trials, with Fate fragments at Lv80. Level numbers differ from Maxroll, so treat them as approximate. — [poe2db](https://poe2db.tw/us/Ascendancy_class)
- The Sekhemas pinnacle boss is Zarokh, the Temporal. The Chaos final boss is The Trialmaster. — [Stratlore](https://poe2.stratlore.com/en/guides/ascendancy-points-trials-guide/)

### Inferences
- Gating ascendancy power behind two different challenge-mode minigames (roguelite floors vs survival waves) at fixed level bands (~22, ~40, ~60, ~75) is a clean idle-game milestone structure: 4 "ascension trials", each +2 points.
- With about 14–15 ascendancy nodes and 8 points, a player commits to roughly 3–4 notables. Each ascendancy therefore supports 2–4 sub-archetypes.

### Gaps
- Exact level requirements differ between poe2db and Maxroll. The official current values for 0.5.5 were not verified.

## 7. Respec cost and build flexibility

### Takeaway
Respec in POE2 is **gold-only**; no Orb of Regret was found in any POE2 source. The cost per refunded point **scales with character level**: the wiki table starts at 15/19/25/31 gold for levels 1–4, and one early guide quoted 247 gold per point. Other costs:
- Changing a travel node's attribute is **50%** of a normal refund.
- Refunding ascendancy points costs **5×** a normal point.
- Since **0.2.0f** you can switch to another ascendancy of the **same class** by refunding all ascendancy points and re-running a trial. Changing base class is impossible.

### Cited Findings
- Refunding costs gold and is "dynamic", changing with character level. You "get 50% off when Refunding the Attribute nodes". It is "much easier to Refund points earlier than in PoE 1". Respec is done at The Hooded One (Act 1), or Doryani in your hideout later. — [Maxroll](https://maxroll.gg/poe2/resources/poe-2-passive-tree-and-dual-specialization)
- Refund cost table: Level 1: 15 gold, Level 2: 19, Level 3: 25, Level 4: 31 (higher levels truncated). — [poe2wiki Respec (wiki snippet)](https://www.poe2wiki.net/wiki/Respec)
- A Dec 2024 guide quoted "247 gold for each passive point you refund" (level unstated, outdated). — [The Outer Haven](https://theouterhaven.net/2024/12/path-of-exile-2-guide-how-to-refund-your-skill-points)
- Ascendancy points cost "five times the cost of standard ones". — [Gfinity](https://www.gfinityesports.com/article/path-of-exile-2-how-to-respec-skill-points)
- Gfinity also claims you can only refund the most recently spent points. This is probably a simplification of tree-connectivity rules and is not verified.
- The ascendancy refund is "5× the cost of a normal passive-point respec, paid in gold". Respeccing only switches between ascendancies of the same class (e.g. Deadeye↔Pathfinder); a class change means a new character. The page was verified against 0.5.4b on 2026-07-04. — [Timesaver respec tool](https://timesaver.gg/tools/poe-2/ascendancy/respec)
- 0.2.0f patch: "redoing an Ascendancy Trial now allows you to respec which Ascendancy Class you have chosen at the Ascension device", if the trial grants the number of points you already have. Points must be refunded first via Balbala or the Trialmaster. — [GamingBolt](https://gamingbolt.com/path-of-exile-2-patch-with-ascendancy-respec-charm-changes-and-more-goes-live); [PCGamesN](https://www.pcgamesn.com/path-of-exile-2/update-respec-ascendancy)
- Breach Atlas trees are free to respec (0.5). — [Maxroll](https://maxroll.gg/poe2/news/patch-0-5-return-of-the-ancients-reveal-summary)

### Inferences
- POE2 deliberately lowered the respec barrier versus PoE1, where Orbs of Regret are a scarce currency. Experimentation is cheap early and gets moderately expensive at high level, while the class is a permanent commitment.
- For an idle game: use a level-scaled soft-currency respec, a cheap attribute swap, an expensive ascendancy swap, and no class swap. That preserves both experimentation and identity.

### Gaps
- No current (0.5) gold-cost figure at level 80–100 was found. Sources state only that it scales with level.
- Whether the old Orb of Regret or "Orb of Unmaking" plays any role in POE2 was not confirmed. No source mentioned it, which suggests gold-only.

## 8. Atlas passive tree (endgame), briefly

- A two-tree model separates "how my character fights" (character tree) from "what loot and content I farm" (atlas tree). An idle game can mirror this with a separate "expedition/farm" tree that eventually fills completely, with only the "master" specialization as an exclusive choice.

## 9. Build planning tools, number of viable archetypes, praise/criticism

### Takeaway
Players plan with **Path of Building (PoE2 version, community fork, released 13 Jan 2025)**, poe2db's tree, Maxroll and Mobalytics planners, PoB Archives and poe.ninja. With 22 ascendancies × many skill and weapon combinations there are dozens of viable archetypes, but no authoritative count exists. Common views:
- **Criticism**: small nodes feel weak; "only ~10% of nodes matter"; pathing is confusing; the tree is overwhelming; the limited points (~122–125) curb experimentation.
- **Praise**: removing Life nodes frees points for real choices; the 0.3 expansion is "dense, interconnected"; weapon-set specialization; the tree acts as the main damage multiplier for gear.

### Cited Findings
- PoB for PoE2 launched 13 Jan 2025. It covered basic skill, support gem, aura and ailment support, the skill tree, ascendancies, some uniques and runes. — [Maxroll](https://maxroll.gg/poe2/news/path-of-building-release-for-poe2)

- Criticism: small passive nodes are too weak versus PoE1 (fewer stat lines). Only one cluster per weapon type versus several in PoE1. "Only like 10% of them actually matter." Pathing distances are deceptive. — [PoE forum thread](https://www.pathofexile.com/forum/view-thread/3649980)
- Criticism: the tree is "bloated" with "over 1,500 nodes", many pointless for a given class, and 122 endgame points leave little room to experiment. — [PoE forum](https://www.pathofexile.com/forum/view-thread/3767066)
- Many nodes are useless until more weapons, classes and skills are released. — [Steam discussion](https://steamcommunity.com/app/2694490/discussions/0/598517526977119081)

- Praise for 0.3: the tree is "dense, interconnected" and "clearly designed to push build variety". — [poe-vault](https://www.poe-vault.com/poe2/news/poe2s-passive-tree-got-huge-here-is-the-before-and-after)

### Inferences
- The key lesson for an idle adaptation is that depth comes from scarce points, keystone trade-offs, ascendancy rule-breakers and jewels/gear interacting, not from node count. A much smaller tree (e.g. 150–300 nodes, about 40–60 points) with the same node-type ratios can deliver similar decision density without the "90% useless nodes" complaint.
- Provide an in-game planner and cheap early respec. POE2 players rely heavily on external tools (PoB) because the tree is opaque.
