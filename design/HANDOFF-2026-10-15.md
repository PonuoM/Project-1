## Pipeline (proven on Mara)
1. Start frame: character sprite with its weapon recoloured to violet ID `#7a3cff` → `design/tools/violet_weapon.py`
   → `design/motion/_inputs/<name>-violet-1280x720.png` (+ `-end.png` copy for the last frame; the app rejects the
   same file twice). Check sheet: `_inputs/check-sheet.png`.
2. H3 in MiniMax Design, first frame = last frame = start image (death: first only), 768P, 5 s.
   Files the app's video tool uses must be inside the app project folder: inputs were copied to
   `C:\Users\user\Movies\Hub\Projects\Read the file C AppS\inputs\` (+ BATCH-01.md). Outside paths fail with
   "Path traversal detected". The agent tends to route into an "ad-tvc" workflow (brief/research/storyboard) — tell
   it to skip all stages and call the video tool directly.
3. Generated clips land in `C:\Users\user\Movies\Hub\Projects\<project>\*.mp4` (ignore the "H3 PlayGround" sample
   projects). Copy to `design/motion/<name>/<move>/video.mp4`.
4. Convert: `python -X utf8 design/tools/video_to_sprite.py VIDEO OUT/frames --ref <name>-violet-64.png --scale 8
   --origin 300,168 --key green --crop 128,80,24,16`; then hand-pick fast frames (strip + pick json), loops via
   `design/motion/mara/find_loop.py DIR A B PMIN PMAX`.
5. Weapon swap: `design/tools/weapon_swap.py STRIP OUT --frame-width 128 --blades SHEET --cell N --glow r,g,b`
   (blade sheet layout = Prompt G7). Viewer list: `design/prototypes/chibi-motion/clips.json`
   (http://localhost/Projects-1/design/prototypes/chibi-motion/index.html).
